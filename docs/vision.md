# MyMemories

## Vision

MyMemories is a personal collection application focused on preserving travel memories. The first version of the application is designed around postcards, allowing users to do the following actions:

- Add new postcards and edit the existing ones.
- Browse postcards on their personal collection according different filterss.
- Preview each one of their postcards, presenting its metadata like title, place, date and other information stored.
- Search its postcards on a global map, similar to the option other apps like Google Photos or Instagram do.
- Modify its personal user information and see statistics about its collection.

All of these actions must be done through a clean and visual interface.

While all the actions must be available on the final version on the app, the latter two (map and statistics) are not a priority. The initial stages of the development must focus on the storage, preview and search on the collection.

Although the MVP only supports postcards, the application is designed so that other collectible travel souvenirs (tickets, magnets, museum passes, etc.) with different metadata can be incorporated in future versions without redesigning the system.

The application prioritizes simplicity, visual browsing and long-term maintainability over social features or content sharing.

---

## Goals

- Build a digital album for postcards.
- Easily search and filter the collection.
- Display memories on a world map.
- Preserve high-quality images.
- Support multiple users.
- Be extensible for future souvenir types.

---

## Non-goals

Current versions will NOT include:

- Social features
- Likes or comments
- Public collections
- AI-generated metadata
- Cloud synchronization (initially)
