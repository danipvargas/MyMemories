# AGENTS

This document provides context for AI coding agents.

## Project

MyMemories

A mobile-first application for managing postcard collections.

Current scope is limited to postcards.

---

## Tech stack

Frontend

- React
- TypeScript
- Vite
- TailwindCSS
- shadcn/ui

Backend

- FastAPI
- SQLAlchemy

Database

- PostgreSQL

---

## Coding principles

- TypeScript everywhere.
- Functional React components.
- One component per file.
- Reusable UI.
- Prefer composition.
- Avoid duplicated logic.

---

## Frontend

- Mobile-first.
- Responsive.
- Use Tailwind utilities.
- Prefer shadcn components.

---

## Backend

- REST API.
- SQLAlchemy ORM.
- Images stored on disk.
- PostgreSQL.

---

## Current priorities

1. Mobile interface.
2. Album.
3. Add postcard.
4. Search.
5. Backend integration.

---

## Important decisions

- Original images are never cropped.
- Thumbnails are generated by the backend.
- Every postcard belongs to one user.
- Images are not stored as BLOBs.
