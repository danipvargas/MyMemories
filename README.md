# MyMemories: A simple app to store postcards and souvenirs

MyMemories is a personal project aimed at creating a digital collection of travel memories. While it initially focuses on postcards, the application is designed to support other types of souvenirs like magnets or museum tickets.

Each item in the collection can store metadata such as its location, acquisition date, images, and additional details, making it easy to browse, search, and visualize memories on an interactive map. Besides being a useful personal tool, this project also serves as an opportunity to explore modern backend technologies and software design practices.
